# Champion Voice Lines — drop audio here

Put your voice files in this folder named exactly after each `voiceClipKey`, e.g.:

    vo_kain_vs_cecil.mp3
    vo_kain_generic.mp3
    vo_cecil_vs_kain.wav

Supported: `.mp3`, `.wav`, `.ogg`. After adding files, run
**Tools > Project D > Import Champion Interactions** — the importer auto-binds each
clip to its matching line by filename. Files you assign manually are preserved.

Keys are listed in `../interactions.seed.json`. The subtitle text there is ORIGINAL
placeholder copy; replace both the text and the audio with your LICENSED lines
before shipping (the Dissidia battle dialogue is Square Enix's copyrighted material).
