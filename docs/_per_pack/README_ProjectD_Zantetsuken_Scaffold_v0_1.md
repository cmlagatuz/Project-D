# Project D — *Dissidia: Final Fantasy Ultima Pugma Clamoris*

> **Codename:** Zantetsuken  ·  **Status:** Pre-production (v1.0 concept locked)  ·  **Classification: CONFIDENTIAL**
> Mobile-first 5v5 MOBA. Engine target: **Unity** (Unreal fallback per GCD §14.1).

This repository is the engineering realization of the **Game Concept Document v1.0**.
It contains the data-driven gameplay foundation, the fairness-critical objective
systems, an authoritative-server contract, and the test + CI scaffolding needed
to reach the **first playable** (GCD §15.3).

## Getting started

1. Install **Unity 2022 LTS** (or the version fixed after the engine benchmark).
2. Create an empty Unity project and drop the `Assets/` folder in, **or** open this
   folder directly once a `ProjectSettings/` is generated by the editor.
3. Add the test assembly reference and run **Window ▸ General ▸ Test Runner ▸ EditMode**.
4. Author `GameData/` ScriptableObjects: 6 summons, Odin, 4 manifestations, the
   Goblin set, and one champion per role for the first playable.
5. Put `MatchBootstrap` on a scene object, assign the objective data, press Play,
   and confirm the console prints a **disclosed** summon order from the seed.

See `docs/sprint-plan.md` for the sequenced backlog and `docs/coding-standards.md`
for conventions. The engine-agnostic logic (combat, objectives, utilities) is
deliberately Unity-free so the dedicated server can reuse it — see `server/`.
