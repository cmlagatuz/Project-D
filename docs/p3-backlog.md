# Project D — P3 Backlog (Competitive Integrity & Live-Service Depth)

> Codename Zantetsuken · CONFIDENTIAL · All original design.
P3 = the next tier after P0-P2: competitive integrity, social depth, live-service progression.

## 10 systems
1. Honor & Report — commendations + reports, behavior score, restriction tiers, ranked gate.
2. Replay — recording (header/events/keyframes) + playback (seek/speed).
3. Spectator — broadcast delay (anti-ghosting) + fog + viewer roster.
4. Guild/Clan — roles, join requests, capacity, guild XP -> level.
5. Battle Pass — free + premium tiered track, XP -> tiers, claim gating.
6. Party/Lobby — invites, ready-check, size caps, party-avg MMR.
7. Champion Mastery — points -> levels (L5) -> tokens.
8. Practice tool — sandbox config + shareable code.
9. News feed — categorized items, pinned, per-player unread.
10. Integrity signals — server-side impossible-action checks -> flag for review.
