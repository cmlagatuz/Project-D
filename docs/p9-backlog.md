# Project D — P9 Backlog (Narrative, Progression & Player Expression)

> Codename Zantetsuken · CONFIDENTIAL · All original design.
P9 = the identity, story, and long-tail progression systems that give the game soul:
lore, achievements, titles, world events, and cosmetic expression. Engine-agnostic +
unit-tested. FF-flavored names remain placeholders.

## 10 systems
1.  Narrative/quest chains — ordered story beats with prerequisites + branching.
2.  Champion codex — unlockable lore entries gated by mastery/achievements.
3.  Cinematic timeline — a keyframed cutscene sequencer (events fire on the timeline).
4.  Voice-line director — contextual VO selection with cooldowns + priority.
5.  World events — server-wide meta events with community progress goals.
6.  Achievements — trackable goals with tiers, progress, and unlock rewards.
7.  Titles/flair — earnable titles + a display registry (one active).
8.  Cosmetic emporium — rotating featured cosmetics + bundles + discounts.
9.  Daily login/streak — login calendar with streak bonuses + catch-up rules.
10. Progression paths — multi-track long-term goals (mastery/collector/ranked).
