# P13 — Systems Reference (World Persistence & Living-World)
> Project D · Codename Zantetsuken · CONFIDENTIAL · All original design. Engine-agnostic + tested (P13Tests, 12).
1.  WorldMap/WorldMap — regions with majority-control resolution + change log + dominant faction.
2.  Narrative/NarrativeGraph — branching story with flag/state-conditional choices + visit tracking.
3.  Housing/PlayerHouse — rooms + placeable decor, rating with theme-cohesion bonus.
4.  Companions/CompanionRoster — collectible companions that level + unlock traits + equip.
5.  CraftMastery/MasteryTree — crafting skill tree, recipe unlocks, mastery-improved quality rolls.
6.  FactionWar/FactionWar — 3-faction territory contest, weekly winner + carryover reset.
7.  Seasonal/SeasonalCycle — deterministic season + weather cycle + ambient BGM keys.
8.  Lore/LoreCodex — discovery encyclopedia with entry links + completion sets + rewards.
9.  Mentorship/MentorProgram — veteran<->newcomer pairing, shared goals, graduation rewards.
10. Legacy/LegacyRewards — veteran-tenure milestones -> prestige cosmetics + evolving title.

Plus: P12 Ops Console UI (Tools > Project D > Build Ops Console) — live tiles for schedule,
moderation, incidents, rollout, and clan-war standings, driven by the P12 cores.
