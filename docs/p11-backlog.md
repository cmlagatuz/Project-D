# Project D — P11 Backlog (Social Economy & Community Systems)

> Codename Zantetsuken · CONFIDENTIAL · All original design.
P11 = the social/economy depth that turns a playerbase into a community: guild
progression, player-to-player trading, a crafting economy, prestige/collections, live
community tournaments, and engagement loops. Engine-agnostic + unit-tested; all
cosmetic/soft-currency (no pay-to-win), with anti-abuse guardrails.

## 10 systems
1.  Guild progression 2.0 — guild levels, perks, weekly quests, contribution ledger.
2.  Player trading — offer/escrow/accept with untradeable rules + trade-window guard.
3.  Crafting economy — shards -> craft cosmetics; disenchant duplicates -> essence.
4.  Prestige system — post-max-level prestige tiers with cosmetic-only rewards.
5.  Collections/album — collectible completion tracking with set bonuses (cosmetic).
6.  Live community tournaments — open-bracket registration + auto-seeding + progression.
7.  Spectator predictions — free predict-the-winner with a fun points ledger (no real money).
8.  Champion rotation — weekly free-rotation scheduler (deterministic per week).
9.  New-player funnel — staged onboarding milestones with unlock gating + rewards.
10. Endorsements — post-match positive-only endorsements feeding a reputation score.
